# 🕌 وبسایت نماز

وبسایت جامع و ریسپانسیو درباره **نماز** به زبان فارسی که با HTML، CSS و JavaScript خالص ساخته شده است.

## امکانات

- ✨ طراحی مدرن و ریسپانسیو با پشتیبانی کامل راست‌چین (RTL)
- 📖 معرفی اهمیت نماز با آیات و روایات
- 🕋 معرفی نمازهای پنج‌گانه روزانه + نماز جمعه
- 🧭 آموزش گام‌به‌گام نماز (از وضو تا سلام)
- ⏰ **محاسبه اوقات شرعی** به صورت تقریبی برای چند شهر ایران
- ❓ بخش پرسش‌های پرتکرار (FAQ) با انیمیشن

## ساختار فایل‌ها

```
namaz-site/
├── index.html   # ساختار اصلی صفحه
├── style.css    # استایل‌ها و طراحی
└── script.js    # منو، FAQ و محاسبه اوقات شرعی
```

## اجرای محلی

کافیست فایل `index.html` را در مرورگر باز کنید. نیازی به سرور نیست.
